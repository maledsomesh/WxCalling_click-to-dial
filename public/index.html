Click-to-Call test page

Webex Calling Customer Assist guest calling. Use the Call us button (bottom right) to call your configured queue from this browser.

How to test

  1. Sign an agent of the destination queue in to the Webex App and make them available.
  2. Open Call us, optionally enter a name, then press Start call.
  3. Allow the microphone when the browser asks.
  4. The agent's Webex App rings with the guest name. Answer it and check two-way audio.
  5. Try Mute, Hold, Keypad (for auto attendant menus) and End call.
